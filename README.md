# 借来的远方 · 折光之城

第一人称 3D 空间解谜游戏。六关完整旅程，教学融入第一关，难度逐步递进。
使用电脑键盘鼠标；无需安装、登录或联网加载素材。

[打开游戏](https://guigui-dl.github.io/borrowed-distance/) · [下载离线 HTML](https://github.com/guigui-DL/borrowed-distance/raw/refs/heads/main/index.html)

## 六个空间

| 顺序 | 章节 | 学会什么 |
| --- | --- | --- |
| 01 | 借一个台阶 | 亲手缩放物体、拍照、显影、收回，再走过照片里的桥 |
| 02 | 泳池来信 | 将楼梯接到高台，从特定视点把三段圆弧对齐，得到下一座桥 |
| 03 | 折叠的家 | 放大小房子进入更大的庭院，把屋外灯光通过照片带进去 |
| 04 | 留白花园 | 缩小方块稳定地址，跟随鹿，用同一片负片通过两道循环影墙 |
| 05 | 影子成路 | 尺寸改变影长；拍下长影，移开人偶，将照片变成实体道路 |
| 06 | 月光归档 | 剪开画面进入弯路，在观测椅上观察月亮，用回声与月光同时接通机关 |

开始旅程始终从 01 出发，关卡菜单和出口按 01 → 06 排列。
标题页可以自由选章；继续按钮读取本机本版的通关进度。
旧版 11 章的编号不映射到新旅程，以免进入错误章节。

## 操作与引导

首页可选择开启指引；游戏内按 **G** 随时开关。
指引显示当前目标、按键、目标方向和规则解释，并按真实操作推进。
**H** 暂停游戏查看分步线索，没有阅读倒计时。关指引不会跳过第一关或改变机关。

| 操作 | 按键 |
| --- | --- |
| 移动 / 跳跃 / 快走 | WASD / 空格 / Shift |
| 环顾 | 鼠标；备用为右键拖动或方向键 |
| 拿起、放下、领取、坐下 | E |
| 拿住时推远放大、拉近缩小 | 滚轮 / + / − |
| 保存物体或影子的照片 | P |
| 举起 / 放下照片 | C |
| 将标注「✓ 可显影」的预览变成实体 | F |
| 切换照片 / 旋转预览 | Tab、1–5 / Q、E |
| 收回最近显影 / 撤销物体操作 | X / Z |
| 录制与结束回声（第 06 章） | V |
| 指引开关 / 详细线索 / 重置 / 暂停 | G / H / R / Esc |

放大后的房子可空手对准按 F 进入。观测椅 E 坐下，WASD / 空格起身。
[完整解法（剧透）](docs/HINTS.txt) · [离线操作说明](docs/README.txt)

## 画面更新

本版参考交错阶梯、粉色庭院与层叠拱廊的体块比例和空间组织，重新设计全部六关。
每关采用独立的低饱和彩色配色；保留第一人称操作，建筑感参考《纪念碑谷》的清晰体块与框景。

| 关卡 | 色彩 | 空间设计 |
| --- | --- | --- |
| 01 | 珊瑚粉、奶油白、青灰 | 两段可连续登上的折返楼梯，跨层拱廊围绕教学场地 |
| 02 | 青碧、象牙白、珊瑚点缀 | 对向阶梯与三层回廊围合天井，两次显影补上断开的路线 |
| 03 | 紫藤、雾蓝、暖白 | 街区向上卷曲，小屋内是更大的三层庭院 |
| 04 | 薄荷、玉绿、米白 | 重复拱廊与嵌套庭院形成循环感，白弧标记对应可剪开的入口 |
| 05 | 杏橘、藕粉、象牙白 | 长廊与屋顶阶梯框住留空的舞台，让影子成为道路 |
| 06 | 蓝紫、月白、暖杏 | 多个高度的回廊与斜向楼梯叠合，拱门框住最终的月亮 |

拱洞直接从墙体网格中挖出；楼梯具有实体踏步、侧墙、转角平台。
合并静态建筑零件以控制绘制数量，保留机关与碰撞对象的独立操作。
材质、渐变天空与水面倒影均在程序内生成，无需外部模型、图片或 CDN。
显影通过青绿/珊瑚色以及「✓ 可显影 / × 位置未就绪」共同反馈。

## 离线与发布

单独下载根目录 `index.html`，用电脑 Chrome 或 Edge 打开即可，运行不需要服务器。
图形加速应开启。本作使用 WebGL，不提供手机触屏操作。

GitHub Pages：Settings → Pages → Deploy from a branch → main → /(root)。
之后更新根目录 `index.html` 即更新网页，分享地址不变。

## 开发

```sh
python3 src/build.py
node src/verify.cjs
```

`build.py` 将引擎、界面、游戏逻辑、场景模型与六章编排整合进单个 HTML。
`architecture.js` 管理本版六关建筑、材质、光照与水面倒影。
`campaign.js` 管理公开顺序；内部场景 ID 仅供旧场景几何复用，不对应菜单编号。
`verify.cjs` 使用真实 Three.js 几何、碰撞与游戏操作，模拟渲染器，检查六章跳转、
拍照/显影/收回、循环、影子、回声、视点、存档及可关闭的教学。
逻辑检查不代替真实浏览器画面与设备兼容性测试。

[参考图转化](docs/IMAGE-NOTES.txt) · [调研记录与实现范围](docs/RESEARCH.txt)

所有场景为程序化三维几何，没有将用户原图作为背景素材嵌入。
相机记录指定物体和影子，楼梯/桥为结构照片；负片仅作用于标记墙面。
