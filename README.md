# 借来的远方 III：园林之外

一个可直接下载、完全离线游玩的第一人称 3D 空间解谜游戏。
包含 **独立新手练习室 + 11 个正式章节**，无需安装游戏引擎或运行服务器。

## 分享网页

启用 GitHub Pages 后，游戏地址为：https://guigui-dl.github.io/borrowed-distance/

发布设置：Settings → Pages → Deploy from a branch → main → /(root) → Save。
这是电脑键盘鼠标游戏；朋友打开网页即可进入新手练习，无需安装。
仍可下载根目录 `index.html` 完全离线游玩。

## 开始游戏

下载整个项目后，用电脑上的 Chrome 或 Edge 打开 `index.html`。
不要把 GitHub 源码浏览页当作游戏运行页；请下载文件后在本地打开。

首次开启指引点击“开始旅程”会先进入练习室：亲手放大方块、验证尺寸、
拍照生成副本、收回副本、显影桥并实际走过。完成后自动进入园林第 07 章。
标题页可选任意章节，也可重玩练习。关闭指引则直接进入园林。

## 核心操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 跳跃 / 快走 | WASD / 空格 / Shift |
| 环顾 | 鼠标；备用为右键拖动或方向键 |
| 拿起、放下、领取、坐下 | E |
| 拿住时推远放大、拉近缩小 | 滚轮 / + / − |
| 保存物体或影子的照片 | P |
| 举起照片 / 放下照片 | C |
| 将有效预览变成实体 | F |
| 切换照片 | Tab / 1–5 |
| 收回最近显影 / 撤销物体操作 | X / Z |
| 回声录制与结束（09、11 章） | V |
| 开关操作指引 / 暂停看详细线索 | G / H |
| 重置本章 / 暂停 | R / Esc |

照片保存指定物体或预制结构；负片只剪开标记墙面。
放大后的房子可空手对准按 F 进入。红椅按 E 坐下，WASD / 空格起身。
更多细节见 [操作说明](docs/README.txt)，卡关时见 [关卡解法](docs/HINTS.txt)。

## 场景与机制

原六章包含透视缩放、循环走廊、错视对齐、物体副本、携光穿门与组合机关。
新增五章采用卷曲街区、绿篱与鹿、红衣队列、落地灯与长影、
幕布公路、阶梯宫殿、红椅与月亮等空间主题。

参考图与玩法的对应见 [IMAGE-NOTES](docs/IMAGE-NOTES.txt)。
所有场景使用程序化三维几何，没有嵌入用户上传的原图。
调研来源及实现边界见 [RESEARCH](docs/RESEARCH.txt) 与游戏内说明。

## 修改与构建

游戏和 Three.js 均已内嵌在 HTML 中，游玩无需依赖安装。
修改 `src` 后，用 Python 3 重新生成根目录与 `dist` 下的入口：

```sh
python3 src/build.py
```

如需运行现有逻辑检查，使用 Node.js：

```sh
node src/verify.cjs
```

验证覆盖 11 章与练习室的碰撞、透视缩放、拍照显影、收回、回声和机关，
以及指引开关和新手教学推进。它使用真实三维几何与模拟渲染器，
不等同于浏览器画面或设备兼容性实测。
