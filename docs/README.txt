借来的远方 III：园林之外
独立新手练习室 + 五个园林新章 + 原六章，共 11 个正式章节。单文件离线游戏。

【打开】
把 Borrowed-Distance.html 下载到电脑，用 Chrome 或 Edge 打开。
ZIP 用户先解压，再打开 START-GAME.html。
不需要安装、网络、本地服务器或任何代码环境。
不要在聊天窗口的文件预览器里运行。
首次开启指引并点击“开始旅程”，会先进入独立的新手练习室；通关后进入第 07 章。
关闭指引或已完成练习时，直接从第 07 章开始。标题页仍可选择任何章节。
“从零练习”可随时重玩；练习中 Esc 暂停，再选“跳过练习，进入园林”。

【给完全没玩过这类游戏的玩家】
不需要知道《超阈值空间》或《取景器》的规则。
新手练习每次只要求一个动作，由实际完成状态推进，没有倒计时：
1. 走到圆圈；用准星选中黄色方块，E 拿起。
2. 平视按 + 或向上滚轮推远，看实际尺寸从 0.60 m 增至至少 1.40 m。
3. 放进黄色圆环，验证大方块确实能接通机关。
4. P 拍摄原件，C 举照片，F 在绿色落点生成实物，看到原件与副本共存。
5. X 收回副本，验证原件与照片还在。
6. 领取桥照片，用同样的 C → F 显影，再亲自走过这座桥。
练习中精简按键，只显示当前需要的操作；旁边显示尺寸或原件/副本数量。
正式章节在“先理解本章规则”中解释留白、回声、视点对齐等含义。
放置失败时会说明是没有地面、离自己太近、被物体挡住，还是道路两端没搭好。
练习室可以重置、跳过、重玩。关闭指引不会改变任何谜题条件。

【操作指引 · 可开关】
默认开启。标题页勾选“开启操作指引”，或暂停菜单中切换；游戏中按 G 立即开关。
选择会保存在本机，重新打开文件仍会沿用；受限存储时不影响本次选择。
初次游玩先教 WASD 移动、鼠标 / 右键拖动 / 方向键环顾，完成后自动进入关卡指引。
左侧指引显示：当前步骤、具体按键、目标方向与距离，随物体、照片与机关状态自动更新。
方向标显示直线距离，不是自动寻路；需要自行绕过墙壁、沿楼梯或道路前进。
拿物体、举照片、坐下、录制回声时，操作说明会切换为当前动作。
H 打开详细线索并暂停游戏：既显示当前进度对应的建议，也可前后翻阅本章线索。
按 H、Esc 或“继续探索”返回；阅读没有时限，关闭操作指引后仍可用 H。
关闭指引只隐藏教学面板与目标标记，仍保留基本准星互动反馈、机关状态和按键速查。
暂停菜单可选择“重新学习移动与视角”。指引不会自动解谜，也不会改变任何通关条件。

【新章与图像灵感】
07 卷起的街区：弧形草地与重复住宅。放大房子并进入，把灯的照片带入内部庭院。
08 鹿走过的留白：高绿篱、鹿、白弧、黑洞负片。一片留白重复剪开两处正确通道。
09 少一个人的合唱：红色队列与缺席。录下回声，让人偶、来客、回声占位，保留一个空位。
10 影子先抵达：金色灯阵与长影。缩放人偶改变影长，拍摄影子，显影成道路。
11 月亮停在幕布背面：幕布公路、阶梯宫殿、红椅、月亮与拱门。
   剪开画面进入弯路，从红椅上的视点借走月光，留下回声后离开。
原 01–06 章完整保留；完成第 06 章会继续到第 07 章。

【控制】
WASD 移动 / Shift 快走 / 空格 跳跃。
鼠标环顾 / Esc 暂停。鼠标锁定失败时可按住右键拖动，或用方向键。
E / 左键：拿起、放下、领取物品；面对红椅按 E 坐下。
拿物体时滚轮或 + / - 调整透视距离：推远放大，拉近缩小。
P：拍摄瞄准的可操作物体；第 10 章可拍摄地上的长影。
C：举起 / 放下照片。F / 左键：把有效预览显影。
举照片时滚轮调距离，Q / E 转 90 度，1–5 / Tab 切换照片。
留白负片不在空地放置：把它对准带白弧标记的绿篱或幕布，F 剪开。
F：没举照片时，对准放大到至少 2.8 米的房子，可进入。
V：09 与 11 章录制路线；再按 V 结束，最多 6 秒。
回声重走一次你的路线，之后永久停在终点；重新录制会替换旧回声。
X：收回最近一次显影。留白收回后墙会恢复，先走出墙体再收回。
Z：撤销最近物体操作，最多 16 次。不会撤销已发现线索或录制的回声。
G：开关操作指引。H：暂停并阅读详细线索。R：重置当前章。WASD / 空格：从红椅起身。
暂停菜单可调视野、灵敏度、音效和画质。流畅画质降低分辨率与门内刷新频率。

【几个关键规则】
照片保存拍摄时的尺寸、种类或影长，后来移动原件不会改变这张照片。
第 10 章拍下长影后，先移开人偶，让路口空出来，再显影道路。
负片只剪开白弧标记的面板，可前后使用；同一张留白只能维持一个通道。
人偶圈要求尺寸不大于 1.05 米。留空圈要求没有你、回声或任何放下的物体。
第 11 章需要真正按 E 坐在中间红椅，再环顾使弧线重合，才能获得月光照片。

【恢复与存档】
角色掉落返回检查点，丢失物体会回到安全位置。
R 重置本章，标题页可直接选章，无需重复前面的章节。
本机存储保存到达的章节、指引开关和基础教学完成状态，不保存房间内每个物体的位置。
隐私模式或受限文件存储可能不保留章节记录，不影响自由选章。

【实现范围】
空间、房屋、草地、绿篱、鹿、队列、落地灯、红椅、宫殿和道路均为程序化 3D 几何。
本作借鉴用户上传九图的空间结构与色彩，没有直接嵌入原图或相关影视素材。
卷起街区是可探索场景中的弯曲建筑景观，不包含全球重力旋转。
房门以局部空间转换进入独立庭院；普通折叠门保留动态视图和双向穿越。
照片保存指定可操作物体或预制建筑。负片在指定面板开孔，不支持任意模型的自由裁切。
影长依据灯高、人偶高度与水平距离计算，以风格化道路表达；不是任意光学阴影的网格重建。
回声只重放路线并停在终点，不重演取物动作，不是自主队友。
原六章的机制、源码调研记录和限制继续适用，详见游戏内调研页和 RESEARCH.txt。
