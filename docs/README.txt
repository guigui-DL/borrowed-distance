借来的远方 · 混凝土与水

离线：双击 Borrowed-Distance.html 或 index.html，用电脑 Chrome / Edge 打开。
无需网络、服务器或安装。需键盘鼠标和 WebGL 图形加速；手机没有触屏操作。
网页：https://guigui-dl.github.io/borrowed-distance/

只有六个公开章节，顺序是：
01 借一个台阶 → 02 泳池来信 → 03 折叠的家 →
04 留白花园 → 05 影子成路 → 06 月光归档。
开始旅程从第一章开始，教学就是第一章的一部分。
标题页可自由选章，继续按钮读取本机本版通关进度；旧版编号不沿用。

WASD 移动，空格跳跃，Shift 快走。
鼠标转向；无法锁定时，用右键拖动或方向键。
E 拿起 / 放下 / 领取 / 坐下；滚轮或 + − 改变拿住物体的实际尺寸。
P 拍照；C 举照片；标注「✓ 可显影」的预览时 F 显影。Tab / 1–5 切换照片。
Q / E 旋转预览；X 收回显影，Z 撤销物体操作。
F 也可在空手时进入已放大的房屋。
第六章 V 录制 / 结束回声。坐上观测椅后 WASD / 空格起身。
G 随时开关指引；H 暂停读分步线索；R 重置本章；Esc 暂停与设置。

指引包括：规则解释、当前动作、对应按键、目标方向，以及依据机关进度自动切换的步骤。
第一章用实际拿取、缩放、拍照、显影、收回和过桥教规则，无阅读倒计时。
画面不流畅时，在暂停菜单将画质改为“流畅”。
